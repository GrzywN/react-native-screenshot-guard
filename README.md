# react-native-screenshot-guard

Per-screen screenshot and screen recording protection for React Native apps. Built using Turbo Modules.apps.Expo apps.

## Installation


```sh
npm install react-native-screenshot-guard
```


## Usage


```js
import { multiply } from 'react-native-screenshot-guard';

// ...

const result = multiply(3, 7);
```
